## A. 執行期報錯（有錯誤訊息的）

### A1. `RuntimeError: Expected all tensors to be on the same device`

```python
# 原因：模型在 GPU、資料在 CPU（或反過來）
x = x.to(device)              # ✅ 記得重新賦值！x.to(device) 不會就地修改
model = model.to(device)

# 隱藏兇手：在 __init__ 建了 tensor 但沒註冊成 buffer
self.pe = torch.zeros(...)                        # ❌
self.register_buffer("pe", torch.zeros(...))      # ✅
```

### A2. `RuntimeError: expected scalar type Float but found Double`

```python
# 原因：NumPy 預設 float64
x = torch.from_numpy(arr.astype(np.float32))      # ✅
x = torch.as_tensor(arr, dtype=torch.float32)     # ✅
```

### A3. `RuntimeError: mat1 and mat2 shapes cannot be multiplied (32x400 and 512x10)`

```python
# 原因：nn.Linear 的 in_features 算錯
# 解法：用 torchinfo 看實際 shape，或臨時 print
x = self.features(x)
print(x.shape)                # 看攤平前是什麼
x = x.flatten(1)
print(x.shape)                # 這個數字就是 Linear 的 in_features

# 一勞永逸的寫法：用 AdaptiveAvgPool 讓尺寸固定
nn.AdaptiveAvgPool2d(1)       # 不管輸入多大都輸出 (B, C, 1, 1)
```

### A4. `RuntimeError: view size is not compatible with input tensor's size and stride`

```python
x.permute(0, 2, 1).view(B, -1)              # ❌
x.permute(0, 2, 1).reshape(B, -1)           # ✅
x.permute(0, 2, 1).contiguous().view(B, -1) # ✅
```

### A5. `RuntimeError: Trying to backward through the graph a second time`

```python
# 原因1：同一個 loss backward 兩次
# 原因2：跨 batch 保留了帶圖的 hidden state
hidden = hidden.detach()                    # ✅ 截斷

# 原因3：真的需要兩次 → 但通常可以合併
(loss_a + loss_b).backward()                # ✅ 優先這樣
loss_a.backward(retain_graph=True)          # 最後手段
```

### A6. `RuntimeError: element 0 of tensors does not require grad`

```python
# 原因：loss 沒有連到任何需要梯度的參數
# 檢查：是不是整個包在 no_grad 裡？是不是全部參數都被凍結了？
print(loss.requires_grad, loss.grad_fn)     # 應該是 True 和某個 Backward 物件
```

### A7. `RuntimeError: one of the variables needed for gradient computation has been modified by an inplace operation`

```python
x = self.bn(x)
x += residual                # ❌ 就地修改了 backward 需要的值
x = x + residual             # ✅
```

### A8. `IndexError: Target N is out of bounds` / `index out of range in self`

```python
# 原因：標籤值超過類別數，或標籤從 1 開始編號
print(labels.min(), labels.max())        # 必須是 0 ~ C-1
labels = labels - 1                      # 若原本是 1~C
# Embedding 同理：索引必須 < num_embeddings
```

### A9. `ValueError: Expected input batch_size (32) to match target batch_size (64)`

```python
# 原因：Dataset 的 __getitem__ 回傳的 x 和 y 沒對齊，或 collate 出錯
x, y = next(iter(loader))
print(x.shape, y.shape)      # 第 0 維必須相同
```

### A10. `CUDA out of memory`

見 `12_GPU_AMP_效能.md` §4 的處方順序。最快的三招：
降 batch size → 開 AMP → 驗證迴圈加 `@torch.no_grad()`。

### A11. `RuntimeError: DataLoader worker exited unexpectedly` (Windows)

```python
# 原因：沒有 main guard
if __name__ == "__main__":
    main()
# 或直接 num_workers=0
```

### A12. `Expected 4-dimensional input but got 3-dimensional`

```python
model(img)              # ❌ (3, 32, 32)
model(img[None])        # ✅ (1, 3, 32, 32)
```

### A13. `_pickle.UnpicklingError` / `weights_only` 相關

見 `13_儲存載入與checkpoint.md` §1。

### A14. BatchNorm 在 batch=1 時報錯

```python
# ValueError: Expected more than 1 value per channel when training
DataLoader(..., drop_last=True)          # ✅ 丟掉最後不完整的 batch
# 或改用 GroupNorm / LayerNorm
```

## B. 靜默錯誤（不報錯但結果是錯的）★★ 這些最可怕

### B1. 靜默廣播

```python
pred = model(x)          # (32, 1)
loss = F.mse_loss(pred, y)   # y 是 (32,) → 廣播成 (32,32)！
# ✅ 加 assert
assert pred.shape == y.shape, f"{pred.shape} vs {y.shape}"
```

### B2. 忘記 `optimizer.zero_grad()`

**症狀**：loss 一開始下降然後爆炸，或劇烈震盪。

### B3. 忘記 `model.eval()`

**症狀**：驗證準確率明顯低於訓練，且每次跑結果都不一樣。

### B4. 忘記 `model.train()`（在 eval 之後）

**症狀**：第二個 epoch 開始 dropout 失效，訓練 loss 掉太快、開始過擬合。

### B5. 對 CrossEntropyLoss 先做了 softmax

**症狀**：loss 從 2.3 降到 2.1 就不動了，準確率卡在很低。

```python
return self.fc(x)                   # ✅ 直接回傳 logits
return F.softmax(self.fc(x), -1)    # ❌
```

### B6. 用 Python list 裝子模組

```python
self.layers = [nn.Linear(10,10) for _ in range(3)]     # ❌ 那三層永遠不會被訓練
self.layers = nn.ModuleList([...])                     # ✅
# 檢查：print(sum(p.numel() for p in model.parameters()))
```

### B7. 時序資料用 `random_split` 或 `shuffle` 切分

**症狀**：準確率高得不合理（例如股價漲跌預測 > 85%）。

### B8. 用全部資料算正規化統計量

```python
# ❌ 測試集資訊洩漏（你的 utils.py 目前是這樣）
df["v"] = (df["v"] - df["v"].mean()) / df["v"].std()
# ✅ 只用訓練集算，套用到全部
mu, sd = train_df["v"].mean(), train_df["v"].std()
```

### B9. 驗證集做了隨機資料增強

**症狀**：驗證指標每次都不同，無法比較實驗。

### B10. 標籤與特徵錯位一格

```python
# 檢查方法：直接把幾筆資料印出來用眼睛看
for i in range(5):
    x, y = ds[i]
    print(x[-1], y)          # 最後一天的特徵 vs 標籤，時間對得起來嗎？
```

### B11. `total_loss += loss`（沒有 `.item()`）

**症狀**：記憶體隨 epoch 增長直到 OOM。

### B12. `strict=False` 載入時什麼都沒載到

見 `13_儲存載入與checkpoint.md` §4.1 的驗證法。

### B13. 只跑一個 seed 就下結論

**症狀**：換個 seed 結論就反過來。做研究必須跑 3~5 個 seed 報告 mean ± std。

### B14. 分類不平衡時只看 accuracy

**症狀**：accuracy 90% 但模型其實全部猜同一類。看混淆矩陣就現形。

### B15. 學習率排程 `step()` 呼叫位置錯誤

OneCycle/warmup 要每個 batch 呼叫，其他多數是每個 epoch。放錯地方 lr 會降太快或不降。

## C. 系統化除錯流程

### 步驟 1：讓它報錯（比靜默錯誤好）

```python
torch.autograd.set_detect_anomaly(True)      # 找 nan 來源
assert not torch.isnan(loss), "loss is nan"
assert pred.shape == target.shape
```

### 步驟 2：過擬合測試（★ 最有效的單一測試）

```python
tiny = torch.utils.data.Subset(train_ds, range(32))
loader = DataLoader(tiny, batch_size=32)
for ep in range(300):
    loss, acc = train_one_epoch(model, loader, criterion, optimizer, device)
    if ep % 50 == 0: print(ep, loss, acc)
# loss 應該降到接近 0，acc 應該到 100%
```

| 結果 | 診斷 |
|---|---|
| loss → 0，acc → 100% | ✅ 流程沒問題，去調參 / 加資料 |
| loss 不動 | 梯度沒接上：檢查 zero_grad / backward / step / requires_grad |
| loss 降但 acc 不動 | loss 和 metric 算法不一致（例如 shape 錯） |
| loss = nan | 數值問題：降 lr、檢查 log/sqrt/除法 |

### 步驟 3：二分法定位

```python
# 從最簡單的版本開始，一次加一個東西
# v0: 最簡單的 MLP + 固定資料 → 能過擬合嗎？
# v1: 加上真實資料 → 還能訓練嗎？
# v2: 加上資料增強 → ?
# v3: 換成真正的模型 → ?
# 哪一步壞掉，問題就在那一步
```

### 步驟 4：檢查每一層的輸出

```python
def debug_forward(model, x):
    h = x
    for name, layer in model.named_children():
        h = layer(h)
        print(f"{name:20s} {tuple(h.shape)} "
              f"mean={h.float().mean():.4f} std={h.float().std():.4f} "
              f"nan={torch.isnan(h).any().item()}")
    return h
```

正常的網路，每層輸出的 std 應該維持在 0.1 ~ 10 之間。
如果一路縮小到 1e-5，就是初始化或架構有問題。

### 步驟 5：確認參數真的在變

```python
before = {n: p.clone() for n, p in model.named_parameters()}
# ...訓練一步...
for n, p in model.named_parameters():
    delta = (p - before[n]).abs().sum().item()
    if delta == 0:
        print(f"⚠️ {n} 完全沒變！")
```
