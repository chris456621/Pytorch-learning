## §1 EC 的定位：什麼時候該用它

| 場景 | 梯度下降 | EC |
|---|---|---|
| 目標函數可微 | ★ 快得多 | 慢 |
| 目標函數**不可微**（準確率、延遲、參數量） | ❌ 不能用 | ★ 可以 |
| 離散/組合最佳化（選哪些層、幾個 head） | ❌ 困難 | ★ 自然 |
| **多目標**（同時最佳化準確率和模型大小） | 需加權合併 | ★ 直接給你 Pareto front |
| 目標函數有很多局部極值 | 容易卡住 | ★ 族群多樣性有幫助 |
| 高維（百萬參數） | ★ 高效 | 極慢（維度災難） |
| 評估成本很高（訓練一次要 1 小時） | — | ⚠️ 族群 × 世代 = 很多次訓練 |

> ★ **結論**：不要用 EC 取代反向傳播去訓練網路權重（除非是 ES 那種特殊場景）。
> **EC 的價值在於「梯度到不了的地方」**：超參數、架構、多目標取捨。

## §2 GA 基本框架

```python
import numpy as np

class GA:
    def __init__(self, n_pop, n_dim, bounds, fitness_fn,
                 p_cross=0.9, p_mut=0.1, eta_c=20, eta_m=20, seed=0):
        self.rng = np.random.default_rng(seed)
        self.n_pop, self.n_dim = n_pop, n_dim
        self.lo, self.hi = bounds                    # 各維度上下界，shape (n_dim,)
        self.fitness_fn = fitness_fn
        self.p_cross, self.p_mut = p_cross, p_mut
        self.eta_c, self.eta_m = eta_c, eta_m
        self.pop = self.rng.uniform(self.lo, self.hi, (n_pop, n_dim))

    # ---------- 選擇：二元錦標賽 ----------
    def tournament(self, fit, k=2):
        idx = self.rng.integers(0, self.n_pop, (self.n_pop, k))
        best = idx[np.arange(self.n_pop), fit[idx].argmin(axis=1)]   # 最小化
        return self.pop[best]

    # ---------- 交配：SBX 模擬二元交配 ----------
    def sbx(self, p1, p2):
        u = self.rng.random(self.n_dim)
        beta = np.where(u <= 0.5,
                        (2 * u) ** (1 / (self.eta_c + 1)),
                        (1 / (2 * (1 - u))) ** (1 / (self.eta_c + 1)))
        c1 = 0.5 * ((1 + beta) * p1 + (1 - beta) * p2)
        c2 = 0.5 * ((1 - beta) * p1 + (1 + beta) * p2)
        return np.clip(c1, self.lo, self.hi), np.clip(c2, self.lo, self.hi)

    # ---------- 突變：多項式突變 ----------
    def polynomial_mutation(self, x):
        for i in range(self.n_dim):
            if self.rng.random() > self.p_mut:
                continue
            u = self.rng.random()
            if u < 0.5:
                delta = (2 * u) ** (1 / (self.eta_m + 1)) - 1
            else:
                delta = 1 - (2 * (1 - u)) ** (1 / (self.eta_m + 1))
            x[i] += delta * (self.hi[i] - self.lo[i])
        return np.clip(x, self.lo, self.hi)

    def step(self):
        fit = np.array([self.fitness_fn(ind) for ind in self.pop])
        parents = self.tournament(fit)
        children = []
        for i in range(0, self.n_pop, 2):
            p1, p2 = parents[i], parents[(i + 1) % self.n_pop]
            if self.rng.random() < self.p_cross:
                c1, c2 = self.sbx(p1, p2)
            else:
                c1, c2 = p1.copy(), p2.copy()
            children += [self.polynomial_mutation(c1), self.polynomial_mutation(c2)]
        children = np.array(children[:self.n_pop])

        # ★ 精英保留：合併父代子代取最好的 n_pop 個
        merged = np.vstack([self.pop, children])
        merged_fit = np.array([self.fitness_fn(ind) for ind in merged])
        keep = merged_fit.argsort()[:self.n_pop]
        self.pop = merged[keep]
        return merged_fit[keep[0]]
```

### 逐行拆解「向量化的非支配排序」

這段是全教材 NumPy/PyTorch 廣播用得最兇的一段，值得慢慢拆：

```python
le = (F[:, None, :] <= F[None, :, :]).all(-1)
lt = (F[:, None, :] <  F[None, :, :]).any(-1)
dom = le & lt
```

**`F` 的形狀是 `(N, M)`**：N 個個體、每個有 M 個目標值。

**`F[:, None, :]`** → `(N, 1, M)`
在中間插一個長度 1 的維度（`None` 就是 `np.newaxis`）。

**`F[None, :, :]`** → `(1, N, M)`
在最前面插一維。

**兩者相比較時廣播成 `(N, N, M)`**：
`結果[i][j][m]` = 「個體 i 的第 m 個目標 ≤ 個體 j 的第 m 個目標嗎」。
**一次算出所有個體對所有個體、所有目標的比較** —— 取代了三層 for 迴圈。

**`.all(-1)`** 沿最後一維（目標維）收斂 → `(N, N)`
`le[i][j]` = 「i 在**每個**目標上都不比 j 差」

**`.any(-1)`** → `lt[i][j]` = 「i 至少在**一個**目標上嚴格較好」

**`dom = le & lt`** 兩個條件同時成立 = **i 支配 j**（這就是支配的定義）
- `&` 是逐元素「且」，不能寫 `and`（`and` 對整個陣列取真假值，會報錯）

```python
n = dom.sum(0).clone()          # 每個個體「被幾個人支配」
cur, r = (n == 0), 0
while cur.any():
    rank[cur] = r               # 沒有人支配它 -> 它在第 r 層 front
    n = n - dom[cur].sum(0)     # 移除這一層造成的支配關係
    n[cur] = -1                 # 標記已處理（-1 永遠不等於 0，不會被重複選中）
    cur, r = (n == 0), r + 1
```
- `dom.sum(0)` 沿第 0 維加總 = 「每一欄」的和 = 有幾個人支配 j
- `rank[cur] = r` 是**布林索引賦值**：一次把所有 `cur` 為 True 的位置設成 r
- 這個 while 迴圈就是在剝洋蔥：剝掉最外層的 Pareto front，
  剩下的重新算「被支配次數」，再剝下一層

### 三個運算子的作用

| 運算子 | 作用 | 太強 | 太弱 |
|---|---|---|---|
| **選擇** | 保留好的解（exploitation） | 過早收斂 | 收斂太慢 |
| **交配** | 組合兩個好解的優點 | — | 缺乏組合能力 |
| **突變** | 跳出局部極值（exploration） | 退化成隨機搜尋 | 卡在局部極值 |

> ★ **EC 的核心永遠是 exploration / exploitation 的平衡**，
> 這跟 RL 的 epsilon-greedy 是同一個問題的不同面貌。

## §3 NSGA-II 回顧與向量化加速

你的 `NSGA-II.py` 實作了兩個核心機制：

| 機制 | 目的 |
|---|---|
| **非支配排序** | 把族群分成 Pareto front 層級（rank 0 最好） |
| **擁擠距離** | 同一層內偏好「附近比較空曠」的解 → 維持多樣性 |

```python
import torch

def fast_non_dominated_sort(F):
    """F: (N, M) 目標值矩陣（最小化）。回傳每個個體的 rank。"""
    N = F.shape[0]
    le = (F[:, None, :] <= F[None, :, :]).all(-1)      # 每個目標都不差
    lt = (F[:, None, :] <  F[None, :, :]).any(-1)      # 至少一個嚴格較好
    dom = le & lt                                       # dom[i,j]=True 代表 i 支配 j

    n = dom.sum(0).clone()                              # 被幾個個體支配
    rank = torch.full((N,), -1, dtype=torch.long)
    cur, r = (n == 0), 0
    while cur.any():
        rank[cur] = r
        n = n - dom[cur].sum(0)
        n[cur] = -1                                     # 標記已處理
        cur, r = (n == 0), r + 1
    return rank


def crowding_distance(F):
    """同一層內的擁擠距離。F: (n, M)"""
    n, M = F.shape
    d = torch.zeros(n)
    for m in range(M):
        order = F[:, m].argsort()
        f = F[order, m]
        d[order[0]] = d[order[-1]] = float("inf")       # ★ 邊界解永遠保留
        if n > 2:
            span = (f[-1] - f[0]).clamp(min=1e-12)
            d[order[1:-1]] += (f[2:] - f[:-2]) / span
    return d
```

## §4 EC × 深度學習：三種整合方式 ★

### 4.1 超參數最佳化（最實用）

```python
SPACE = {                        # 搜尋空間定義
    "lr":           ("log",   1e-5, 1e-1),
    "weight_decay": ("log",   1e-6, 1e-1),
    "hidden":       ("int",   32,   512),
    "n_layers":     ("int",   1,    6),
    "dropout":      ("float", 0.0,  0.6),
}

def decode(gene):
    """gene 是 [0,1]^d 的向量 → 真實超參數。"""
    cfg = {}
    for g, (name, (kind, lo, hi)) in zip(gene, SPACE.items()):
        if kind == "log":
            cfg[name] = float(10 ** (np.log10(lo) + g * (np.log10(hi) - np.log10(lo))))
        elif kind == "int":
            cfg[name] = int(round(lo + g * (hi - lo)))
        else:
            cfg[name] = float(lo + g * (hi - lo))
    return cfg

def fitness(gene):
    cfg = decode(gene)
    set_seed(42)
    model = build_model(**cfg)
    val_acc = quick_train(model, cfg, epochs=5)     # ★ 只訓練少量 epoch 當代理
    return -val_acc                                  # 最小化 → 取負
```

> ★ **關鍵技巧：用「便宜的代理評估」**。
> 每個個體都完整訓練 100 epoch 不可行（50 個體 × 30 世代 = 1500 次訓練）。
> 做法：
> - 只訓練 5 個 epoch
> - 只用 10% 訓練資料
> - **Successive halving**：先全部跑一點 → 淘汰一半 → 剩下的跑久一點 → 再淘汰

### 4.3 神經演化（演化權重本身）

```python
# Evolution Strategies（Salimans et al. 2017）
# 完全不用反向傳播，只靠「加雜訊 → 看誰好 → 加權平均」
def es_step(params, fitness_fn, n_pop=50, sigma=0.05, lr=0.01):
    eps = torch.randn(n_pop, params.numel())
    rewards = torch.tensor([fitness_fn(params + sigma * e) for e in eps])
    rewards = (rewards - rewards.mean()) / (rewards.std() + 1e-8)   # ★ 標準化
    grad_est = (eps * rewards[:, None]).mean(0) / sigma             # 梯度估計
    return params + lr * grad_est
```

> ★ ES 的優點是**完全可平行化**（每個 worker 只要傳一個 seed 和一個 reward），
> 且不需要反向傳播，可以處理不可微的 reward。
> 缺點是樣本效率遠低於梯度法，只適合大規模平行的特殊場景。

## §5 EC 做 NAS 神經架構搜尋

```python
BLOCK_TYPES = [conv3x3_block, depthwise_block, residual_block]

def build_from_gene(gene):
    """gene[0]=層數, gene[1]=起始寬度, gene[2:]=每層的 block 類型"""
    n_layers, ch = gene[0], gene[1]
    layers = []
    for i in range(n_layers):
        layers.append(BLOCK_TYPES[gene[2 + i]](ch, ch * 2))
        ch *= 2
    return nn.Sequential(*layers)
```

**Regularized Evolution（Real et al. 2018）** 的關鍵改良：
淘汰時**不是淘汰最差的，而是淘汰最老的**（aging）。
這防止某個「運氣好」的個體長期霸佔族群，維持了探索能力。

```python
from collections import deque
import random

population = deque(maxlen=P)                       # ★ deque 自動淘汰最老的
for cycle in range(C):
```

## §6 實務注意事項

```
1. 一定要有精英保留（elitism），否則最好的解可能在下一代消失
2. 族群大小 vs 世代數的取捨：評估成本高時，寧可少族群多世代
3. 一定要記錄「每一代的最佳值」曲線，才知道有沒有過早收斂
4. ★ 跟 RL 一樣，EC 隨機性大，要跑多個 seed 報告 mean ± std
5. 邊界處理：交配/突變後一定要 clip 回合法範圍
6. 評估函式盡量平行化（multiprocessing）
7. 多目標問題不要自己加權合併成單目標，那會丟失 Pareto front 的資訊
```

**收斂診斷：**

```python
diversity = np.std(pop, axis=0).mean()
# diversity 快速歸零但 fitness 還不夠好 → 過早收斂
# 對策：提高突變率、加大族群、用 aging
```

## §7 EC 跟你學過的其他主題的連結

| 連結 | 說明 |
|---|---|
| EC ↔ **RL** | ES 可以取代 policy gradient；兩者都在解 exploration/exploitation |
| EC ↔ **壓縮** | 用 NSGA-II 搜尋「準確率 vs 參數量」的 Pareto front |
| EC ↔ **NAS** | 演化網路架構本身 |
| EC ↔ **GAN** | 用 EC 搜尋 GAN 的架構或超參數（GAN 極難調，EC 有優勢） |
| EC ↔ **對抗樣本** | 黑箱攻擊（拿不到梯度時只能用 EC） |
