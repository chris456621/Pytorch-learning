## P11：整合研究專案（W25 起）

選一個題目做到底，這會是你未來申請研究所 / 進實驗室的作品：

**題目建議（都跟你現有資料有關）**
1. **Self-supervised 金融時序表徵學習**：用 2330/2344/8028 做對比學習預訓練，再 fine-tune 做漲跌預測，跟從零訓練比較。
2. **VAE + 異常偵測**：用重建誤差偵測股價異常波動日。
3. **NSGA-II 做多目標模型選擇**：同時最佳化「準確率」與「模型參數量」，畫出 Pareto front。
4. **壓縮後的 Transformer**：把你的 `Transformer.py` 用 KD + 量化壓到能在 CPU 即時推論。

**研究報告必備章節**：問題定義 / 相關工作 / 方法 / 實驗設定（含 seed、硬體）/ 結果表格 / 消融實驗 / 討論與限制。
