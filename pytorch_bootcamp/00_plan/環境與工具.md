## 4. 實驗紀律（★ 這一節決定你做研究會不會痛苦）

### 4.1 固定隨機種子

```python
import random, os
import numpy as np
import torch

def set_seed(seed: int = 42, deterministic: bool = False):
    """讓實驗可重現。deterministic=True 會變慢但完全可重現。"""
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    torch.cuda.manual_seed_all(seed)
    os.environ["PYTHONHASHSEED"] = str(seed)
    if deterministic:
        torch.backends.cudnn.deterministic = True
        torch.backends.cudnn.benchmark = False
        # 有些 op 沒有 deterministic 實作，會直接報錯讓你知道
        torch.use_deterministic_algorithms(True, warn_only=True)
    else:
        # 輸入尺寸固定時，benchmark=True 會自動挑最快的卷積演算法
        torch.backends.cudnn.benchmark = True
```

> ⚠️ **重要觀念**：固定 seed **不代表**你的結論是對的。
> 正確做法是**跑 3～5 個不同 seed，報告 mean ± std**。
> 只用一個 seed 就宣稱 A 比 B 好，是初學者最常見的假結論來源。

### 4.2 每次實驗都要記錄的東西

建一個 `experiments.md`，每跑一次就加一列：

| ID | 日期 | 模型 | lr | bs | epochs | 其他 | seed | val_acc | 備註 |
|---|---|---|---|---|---|---|---|---|---|
| E001 | 09/02 | CNN-3層 | 1e-3 | 64 | 20 | Adam | 42 | 0.8721 | baseline |
| E002 | 09/02 | CNN-3層 | 1e-3 | 64 | 20 | +BN | 42 | 0.8944 | BN 有效 |

### 4.3 TensorBoard 基本用法

```python
from torch.utils.tensorboard import SummaryWriter

writer = SummaryWriter("runs/exp001_baseline")   # 每個實驗一個資料夾

for epoch in range(EPOCHS):
    # ... 訓練 ...
    writer.add_scalar("Loss/train", train_loss, epoch)
    writer.add_scalar("Loss/val",   val_loss,   epoch)
    writer.add_scalar("Acc/val",    val_acc,    epoch)
    writer.add_scalar("LR", optimizer.param_groups[0]["lr"], epoch)

    # 看權重分布有沒有爆炸/死掉
    for name, p in model.named_parameters():
        writer.add_histogram(f"weights/{name}", p, epoch)
        if p.grad is not None:
            writer.add_histogram(f"grads/{name}", p.grad, epoch)

writer.close()
```

### 4.4 torchinfo：立刻看懂模型的 shape 流

## 6. Windows 特有的坑

### 6.1 `num_workers > 0` 會爆炸

Windows 用 spawn 而非 fork 啟動子行程，主程式會被重新 import。

```python
# ❌ 直接寫在檔案最外層 → RuntimeError / 無限開新行程
loader = DataLoader(ds, num_workers=4)
for x, y in loader: ...

# ✅ 必須包在 main guard 裡
def main():
    loader = DataLoader(ds, num_workers=4, persistent_workers=True)
    for x, y in loader: ...

if __name__ == "__main__":
    main()
```

> 建議：Windows 上 `num_workers` 設 `4` 通常就夠，設太高反而慢（行程啟動成本高）。
> 資料很小時直接用 `num_workers=0` 反而最快。

### 6.3 8GB VRAM 的現實

RTX 4060 Laptop 8GB 能做的：
- ✅ MNIST / CIFAR-10 全部範例
- ✅ 小型 Transformer（d_model ≤ 512, batch ≤ 64）
- ✅ DCGAN 64×64
- ⚠️ ResNet-50 微調要把 batch 降到 32 以下
- ❌ 從零訓練大型語言模型（用不著，也不需要）

**爆 VRAM 時的處方（依序試）**
1. 降 `batch_size`
2. 開 AMP 混合精度（見 `01_syntax/12_GPU_AMP_效能.md`）→ 省一半記憶體
3. 用 gradient accumulation 模擬大 batch
4. `torch.utils.checkpoint`（用時間換記憶體）
